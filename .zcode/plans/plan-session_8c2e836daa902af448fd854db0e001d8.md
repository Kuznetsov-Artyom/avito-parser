# План: сайт-парсер объявлений Avito с умной сортировкой

## Стек
- **Backend:** Python + FastAPI + Uvicorn (Node.js в системе нет — фронтенд без сборки)
- **Парсинг:** Playwright (headless Chromium, async API) со stealth-настройками, без прокси — паузы 2–5 сек между страницами
- **БД:** SQLite (стандартная библиотека) — история поисков и результаты
- **Геокодирование:** OpenStreetMap Nominatim (httpx) — бесплатно, без ключей
- **Фронтенд:** одна статическая страница (HTML/CSS/ванильный JS), раздаётся FastAPI

## Как это работает
1. **POST /api/search** — пользователь вводит: запрос, город, цену min/max, сколько объявлений парсить (по умолчанию 30), веса критериев. Бэкенд создаёт задачу и сразу отдаёт `search_id`.
2. **Фоновая задача** (без блокировки ответа):
   - Playwright открывает страницу поиска Avito, извлекает объявления (заголовок, цена, ссылка, фото, район);
   - затем по очереди открывает каждое объявление (пауза 2–5 сек) и достаёт: рейтинг продавца (0–5), число отзывов, год регистрации, бейджи, точные координаты товара из JSON map-блока, описание;
   - при признаках блокировки («Доступ ограничен», 429) — останавливается с понятной ошибкой.
3. **GET /api/search/{id}** — фронтенд опрашивает каждые 2 сек: статус + прогресс («обработано 12 из 30») + готовые результаты.
4. **GET /api/geocode?q=** — геокодирование города/адреса через Nominatim (с кэшем).

## Геолокация
- Кнопка «определить автоматически» — Geolocation API браузера;
- ручной ввод города/адреса — геокодирование через Nominatim;
- расстояние — haversine от пользователя до координат объявления.

## Формула сортировки (веса настраиваются слайдерами в UI)
Каждый критерий нормируется в 0–100, итог = средневзвешенная сумма (по умолчанию надёжность 40% / цена 30% / удалённость 30%):
- **Надёжность:** 40% за рейтинг (рейтинг/5) + 30% за число отзывов (логарифмическая шкала) + 20% за возраст аккаунта («на Avito с», до 5 лет) + 10% за бейджи;
- **Цена:** перцентильный ранг цены внутри выдачи (дешевле = выше балл);
- **Удалённость:** 100 − (расстояние / радиус, по умолчанию 50 км) × 100; если координат нет — нейтральный балл.

В результатах — сортировка по итоговому баллу, переключаемая на цену/удалённость/рейтинг; у каждой карточки видно, откуда балл.

## Порядок работ
1. Каркас проекта, requirements, конфиг, .gitignore, README.
2. Модели, БД, geo, scoring (чистая логика + быстрые pytest-тесты на scoring/geo).
3. Playwright-слой: браузер, парсер поиска, парсер объявления.
4. FastAPI: маршруты, фоновые задачи, статика.
5. Фронтенд: форма, слайдеры весов, прогресс-бар, карточки результатов.
6. Установка venv + зависимостей, `playwright install chromium`, запуск сервера и живая проверка парсинга на реальном запросе с отладкой селекторов.

## Риски
- **Python 3.14 + playwright/greenlet:** если wheels не встанут — поставлю Python 3.12 через `uv` (запасной вариант описан в README).
- **Блокировки Avito без прокси:** для личного использования с паузами обычно ок; контекст браузера персистентный (стабильные cookies), все селекторы собраны в одном модуле — легко чинить при изменении вёрстки.
- В README добавлю примечание: автоматический доступ запрещён правилами Avito, инструмент для личного использования с щадящими паузами.
