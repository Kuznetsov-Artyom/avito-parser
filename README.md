# Avito Парсер

Веб-приложение для поиска объявлений на Avito с умной сортировкой по трём критериям:

- **Надёжность продавца** — рейтинг, число отзывов, бейджи («Реквизиты проверены», «Надёжный продавец», ...), возраст аккаунта;
- **Цена** — перцентильный ранг внутри выдачи (дешевле = выше балл);
- **Удалённость** — расстояние от вашей геопозиции до района объявления.

Веса критериев настраиваются слайдерами прямо в интерфейсе (проценты всегда
в сумме дают 100% — двигаете один, остальные подстраиваются), есть пресеты
«Сбалансировано / Надёжность / Дешевле / Ближе». Итоговый балл —
средневзвешенная сумма (0–100). В карточке результата видно, откуда взялся балл.

Умный поиск:
- **Автодополнение** — по мере ввода подсказки подтягиваются из Avito
  (запросы и категории) и из истории ваших прошлых поисков;
- **Автоопределение города** — при кнопке «Определить» (геолокация браузера)
  или вводе адреса город в селекте подставляется сам (обратное геокодирование
  OpenStreetMap, 50+ городов + «Вся Россия»).

## Как это работает

1. Парсер открывает страницу поиска Avito (`https://www.avito.ru/{город}?q=...&pmin=...&pmax=...`)
   в реальном браузере через Playwright и извлекает карточки: цену, район,
   рейтинг и отзывы продавца, бейджи.
2. Районы геокодируются через OpenStreetMap Nominatim, считается расстояние
   до вашей точки (haversine).
3. Объявления получают баллы и сохраняются в SQLite; история поисков доступна по id.

Антибот-защиту обходит настоящий браузер: по умолчанию запускается **Yandex Browser**
(или другой найденный системный Chromium-браузер), и Playwright подключается к нему
по CDP — fingerprint честный, cookies сохраняются в персистентном профиле.
Если системного браузера нет, используется встроенный Playwright Chromium.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium   # запасной браузер
```

Настройки (необязательно): `cp .env.example .env` и отредактируйте.

## Запуск

```bash
source .venv/bin/activate
uvicorn app.main:app --port 8000
# открыть http://127.0.0.1:8000
```

Поиск занимает 10–60 секунд: загрузка страницы поиска + геокодирование районов
(1 запрос/сек — лимит Nominatim).

## Конфигурация (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEFAULT_CITY` | `moskva` | Город по умолчанию |
| `DISTANCE_RADIUS_KM` | `50` | Радиус «близости»: ближе — максимальный балл за удалённость |
| `PAGE_DELAY_MIN/MAX` | `2.0 / 5.0` | Паузы между открытием страниц объявлений (deep scan), сек |
| `MAX_ITEMS` | `30` | Лимит объявлений на один поиск |
| `DEEP_SCAN` | `0` | `1` = дополнительно открывать каждое объявление: возраст аккаунта продавца, точные координаты, больше бейджей. Медленнее и выше риск блокировки |
| `BROWSER_HEADLESS` | `0` | `1` = запускать браузер в headless-режиме |
| `YANDEX_BROWSER_PATH` | авто | Путь к своему Chromium-браузеру |
| `PORT` | `8000` | Порт сервера |

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/search` | Запустить поиск (JSON: `query`, `city`, `price_min/max`, `max_items`, `user_lat/lng` или `user_location`, веса `weight_*`) |
| `GET` | `/api/search/{id}` | Статус + отсортированные результаты (для polling каждые 2 сек) |
| `GET` | `/api/suggest?q=` | Подсказки запроса: живые из Avito + история поисков |
| `GET` | `/api/geocode?q=` | Геокодирование адреса (+ определение города Avito) |
| `GET` | `/api/reverse?lat=&lng=` | Город по координатам (для геолокации) |
| `GET` | `/api/cities` | Список городов для формы |

## Тесты и отладка

```bash
pytest tests/ -q                 # юнит-тесты скоринга и гео
python scripts/debug_search.py   # живая проверка парсера страницы поиска
```

Если Avito поменяет вёрстку и парсер перестанет что-то находить — селекторы
собраны в `app/parser/search.py` (страница поиска) и `app/parser/item.py`
(страница объявления), правьте там.

## Ограничения и здравый смысл

- Автоматический доступ запрещён правилами Avito. Инструмент — для личного
  использования: не ставьте десятки поисков подряд, держите разумные объёмы.
- При блокировке приложение покажет понятную ошибку (HTTP 429/403 или страница
  капчи) — подождите несколько минут, уменьшите `max_items` или увеличьте паузы.
- Точность удалённости — до района (геокодирование по названию района/метро);
  при `DEEP_SCAN=1` используются точные координаты объявления, если Avito их отдаёт.
