# AGENTS.md

Инструкции для ИИ-агентов, работающих с этим репозиторием.

## Проект

Веб-приложение для парсинга объявлений Avito с сортировкой по надёжности продавца,
цене и удалённости. Python 3.12+ / FastAPI + Playwright; фронтенд — ванильные
HTML/JS/CSS без сборки (Node.js не используется). Подробности — в README.md.

## Команды

```bash
source .venv/bin/activate
uvicorn app.main:app --port 8000     # запуск сервера (или ./run.sh)
pytest tests/ -q                     # юнит-тесты (scoring, geo, города)
python scripts/debug_search.py       # живая проверка парсера страницы поиска
playwright install chromium          # запасной браузер (Yandex Browser ставится отдельно)
```

База SQLite и профили браузеров живут в `data/` (в .gitignore). Конфиг —
переменные окружения / `.env` (см. `.env.example`), читаются в `app/config.py`.

## Архитектура

Поток данных: `POST /api/search` → фоновая задача `app/pipeline.py` →
парсеры → скоринг `app/scoring.py` → SQLite `app/db.py` → фронтенд опрашивает
`GET /api/search/{id}` каждые 2 сек.

- `app/parser/browser.py` — браузер: основной режим — системный Yandex Browser
  (или другой Chromium-браузер) через CDP с персистентным профилем;
  fallback — встроенный Playwright Chromium. Здесь же детект блокировок Avito.
- `app/parser/search.py` — страница поиска. В редизайне Avito карточка уже
  содержит рейтинг/отзывы продавца и бейджи, поэтому по умолчанию (`DEEP_SCAN=0`)
  страницы объявлений не открываются.
- `app/parser/item.py` — страница объявления (используется при `DEEP_SCAN=1`).
- `app/parser/suggest.py` — живые подсказки: same-origin `POST /web/3/suggest`
  через вкладку, открытую на avito.ru в нашем браузере.
- `app/parser/urls.py` — построение URL поиска и список городов + матчинг
  названия → slug (`match_city_slug`).
- `app/geo.py` — Nominatim (геокодирование, обратное геокодирование) и haversine.
- `app/static/` — фронтенд: форма, автодополнение, ползунки весов (всегда в
  сумме 100%), карточки результатов.

## Ограничения и подводные камни

- **Avito меняет вёрстку.** Все селекторы — в `app/parser/search.py` (экстрактор
  `_EXTRACT_JS`) и `app/parser/item.py`. Если парсер перестал что-то находить —
  сначала запускайте `python scripts/debug_search.py`, смотрите реальный DOM.
- **Блокировки.** Avito отдаёт 429/страницу капчи; `browser.goto()` распознаёт
  это и кидает `BlockedError` с понятным сообщением — не маскируйте его.
  Паузы между запросами: `PAGE_DELAY_MIN/MAX` в .env.
- **Сироты браузера.** После `kill -9`/`pkill` uvicorn процессы Yandex Browser
  остаются жить и блокируют профиль (`data/browser_profile/yandex`), из-за чего
  новый запуск падает в fallback на Chromium (который быстрее блокируется).
  Лечение: `pkill -f "avito_parser/data/browser_profile"` и перезапуск.
  Не используйте `pkill -f "uvicorn app.main:app"` внутри составной bash-команды —
  паттерн совпадёт с самой командой и убьёт её shell.
- **Nominatim** — не чаще 1 запроса/сек (троттлинг уже встроен в `app/geo.py`),
  всегда с User-Agent. Результаты кэшируются в памяти процесса.
- **Без прокси.** Проект рассчитан на личное использование с щадящими паузами;
  автоматический доступ к Avito запрещён их правилами.

## Соглашения

- Комментарии и docstrings — на русском, лаконичные: объяснять «почему», а не «что».
- Чистая логика (скоринг, гео, матчинг городов) покрывается тестами в `tests/`;
  парсеры и браузер — живая проверка `scripts/debug_search.py`.
- Тексты UI и ошибок — на русском, ошибки парсинга должны быть понятны
  пользователю (что случилось и что сделать).
- Экстракция DOM выполняется JS-скриптами внутри страницы (`page.evaluate`) —
  быстрее и устойчивее, чем разбор HTML в Python; селекторы с fallback-вариантами.
- Фронтенд без фреймворков и сборки: только `app/static/` + `<script src>`,
  fetch к `/api/*`, никакой минификации.
